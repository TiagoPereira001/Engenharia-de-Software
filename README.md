## Como trabalhamos

Seguimos o Scrum, em cinco sprints. O backlog, os sprints e as provas das reuniões estão no Jira (projeto EDS) e a documentação no Confluence.

- [Jira](https://ubi-team-ebw5rr6y.atlassian.net/jira/software/projects/EDS/boards/3)
- [Confluence](https://ubi-team-ebw5rr6y.atlassian.net/wiki/spaces/EDS/overview)

Trabalhamos na branch `main`.

## O que está aqui

| Pasta | Conteúdo |
|---|---|
| `docs/Sprint 1/` | Análise do produto do Sprint 1 (stakeholders, personas, cenários e user stories) |
| `docs/contrato/` | Contrato de equipa, em LaTeX e em PDF |
| `docs/guia-jira/` | Guia para usar o Jira, em LaTeX |
| `docs/registo-ia/` | Registo de uso de IA, em LaTeX |
| `certificados-scrum/` | Certificado Scrum Foundation Professional de cada elemento |

Os documentos em LaTeX compilam no Overleaf com pdfLaTeX. É preciso compilar duas vezes para os números de página saírem certos.
